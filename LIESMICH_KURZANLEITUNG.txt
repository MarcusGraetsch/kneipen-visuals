KURZANLEITUNG: KNEIPEN-VISUALS EINRICHTEN (UBUNTU)
==================================================

VORAUSSETZUNGEN
---------------
Ubuntu 20.04 oder neuer, eine grafische Desktop-Sitzung und eine
funktionierende Audio-Sitzung. Auf älteren Ubuntu-Versionen baut das
Setup projectM bei Bedarf automatisch aus dem offiziellen Quellcode.

INSTALLATION
------------
Öffne das Terminal (Strg + Alt + T) und führe aus:

  git clone https://github.com/MarcusGraetsch/kneipen-visuals.git
  cd kneipen-visuals
  bash setup.sh

WINDOWS (OHNE WSL)
------------------
Öffne Windows PowerShell im Repository-Verzeichnis und führe aus:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1

Danach `start-kneipen-visuals-windows.cmd` doppelklicken. Im projectM-Menü
unter Settings/Audio die gewünschte Mikrofon-, USB- oder Loopback-Quelle
auswählen. Für den Beamer das Fenster auf den zweiten Bildschirm ziehen und
Ctrl+F drücken.

Falls nach dem Benutzerpasswort gefragt wird: eintippen und Enter drücken.

ABEND
-----
1. Beamer per HDMI anschließen und unter Ubuntu den Modus „Erweitern“ wählen.
2. Auf dem Desktop „Kneipen-Visuals starten“ doppelklicken.
3. Das projectM-Fenster auf den Beamer ziehen und F für Vollbild drücken.
4. In „Lautstärkeregler“ unter „Aufnahme“ die gewünschte Audioquelle wählen.
